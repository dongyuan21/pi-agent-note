# 批注模板（边读边用）

复制一条，改字段。一次一个念头。

```text
@chN §x.x 小节标题或关键词
标签: 勘误 | 结构 | 发散 | 保留
锚点: 「原文里方便定位的短引句」
念头: …
期望: 停车场 | 折进正文 | 只讨论 | 直接改（仅勘误）
```

## 分流用语（给 Agent 回显时用）

| 建议 | 含义 |
|------|------|
| 改本章 | 当前章应吸收（通常来自勘误/结构） |
| 挪他章 | 属于已有后章主题，交叉引用即可 |
| 新开章/附录 | 发散太大，本章塞不下 |
| 学习笔记 | 对读者有用、对书结构无必要，不进书 |
